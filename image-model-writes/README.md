# image-model-writes 🍌

**图像模型是画图的，但它也能写字。**

## 来由

`google/gemini-2.5-flash-image` 就是常说的 nano banana。网上都说它是图像模型，那就试试：给它纯文字任务，明说不许画图，它会不会吐字。

会。

后来顺手把 OpenAI 那三个也拉进来对照了一遍。

## 怎么试的

- 文字题六类：诗、微小说、数列、代码、翻译、长文。每题跑一次，数列题另外补跑。
- 提示词统一写「只输出 X」「不要画图」，把画图这条路堵死。
- 调 `modalities: ["image","text"]` 时才允许出图。
- 全部走 OpenRouter，温度用默认值，`max_tokens` 按题目放宽（200–4000）。

|---|---|---|---|
| nano banana | `google/gemini-2.5-flash-image` | $0.30 | $2.50 |

## 第二组：GPT 系

### 回文函数

mini 和全量版给的都是同一个写法，`isalnum()` + 切片，比 nano banana 那版少了 `import re` 和 docstring，更短（5.4 没跑这道）：

```python
def is_palindrome(s):
    t = ''.join(ch.lower() for ch in s if ch.isalnum())
    return t == t[::-1]
```

## ⚠️ 坑一：中文直接塞进 shell 会被弄坏

第一次测出图，收到的是一张**笔记本电脑的产品图**。

第一反应差点记成「GPT 把猫画成笔记本」。但全量版直接回了一句：

> 抱歉，你的文字在我这边显示成了乱码。请再发一遍具体需求（例如：猫的颜色、是否在舞台上、它在做什么——唱歌/弹钢琴等），我就立刻为你生成图片。

**是测试脚本自己把中文直接塞进 curl 命令，字节被 shell 弄坏了。** 换成 Python 写成 UTF-8 的 JSON 文件再发，同样的提示词，猫就画对了。

失败的那张图留在 `images/00-broken-encoding-laptop.jpg`——它在这堆图里唯一的价值就是提醒：**结果是垃圾的时候，先怀疑自己的管道。**

## ⚠️ 坑二：响应体前后会粘垃圾

同一个代理，不同次请求，返回的 JSON 前面会带几十字节空白，后面会粘一段来路不明的字符串（有一次是 2598 字节的随机串）。

直接 `json.load()` 会炸。稳健的写法是找到第一个 `{` 再 `raw_decode`，然后**丢掉剩下的**。仓库里的响应文件已经清理成纯净 JSON。

## ⚠️ 坑三：一轮不算数

**第一次跑数列题：**

- 图像版答 `33`，但说规律是「当前数字乘以 2 减去前一个数字」。验算：17×2−9 = 25，不是 33。**答案蒙对，规律是编的。**
- 纯文本版答 `33`，给「每个数等于前一个数的两倍减 1」，四个例式全对；但夹了一句「减去一个递增的常数 (0, 1, 2, 3, 4, …)」，跟它自己下面列的算式打架。

据此写下结论：**图像模型的推理链被削**。

**补跑 5 次之后，这个结论作废：**

| 臂 | 5 次结果 |
|---|---|
| 图像版 | 4 次规律完全正确（差值 1, 2, 4, 8, 16）；1 次被截断，只剩「33」 |
| 纯文本版 | 5 次全部只回「33」，要求解释也不给 |

六次合计：图像版 4 次完整正确、1 次规律错、1 次被过滤；纯文本版 1 次正确但措辞自相矛盾 + 5 次干脆不解释。

**单发结果不足以支撑任何结论。** [model-crush](../model-crush/) 里已经为这条写过一次（「6/6 比 5/6 可疑」「一轮不算数」），这次原样复发。

## ⚠️ 坑四：`content_filter` 会静默截断

`finish_reason: "content_filter"` 时，`content` 只剩最前面几个字，**不抛错、不提示**。一道纯算术题被过滤过一次。输出短得不正常就先查 `finish_reason`。

## 为什么不进 llm-edge-cases

- 唯一的候选现象（「图像模型推理链被削」）补测之后不成立。
- 「`gpt-image-1` 已下线」是上游的服务状态，不是模型行为现象，而且随时会变。
- 剩下能站住的都是「换个文本模型就完了」的结论，没有工程缓解可言。

够不上那边「可复现现象 + 成因假设 + 缓解」的门槛。
