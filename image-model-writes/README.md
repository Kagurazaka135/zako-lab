# image-model-writes 🍌

**nano banana 是画图的，但它也能写字。**

## 来由

`google/gemini-2.5-flash-image` 就是常说的 nano banana。网上都说它是图像模型，那就试试：给它纯文字任务，明说不许画图，它会不会吐字。

会。

## 怎么试的

- 一共 8 道题，每题跑一次；数列题另外补跑 5 次。
- 提示词统一写「只输出 X」「不要画图」，把画图这条路堵死。
- 全部走 OpenRouter，温度用默认值，`max_tokens` 按题目放宽（200–4000）。
- 数列题另设一个对照臂：纯文本版 `google/gemini-2.5-flash`。

| 题 | 模型 |
|---|---|
| 四行诗 | `gemini-2.5-flash-image` |
| 200 字反转微小说 | `gemini-2.5-flash-image` / `gemini-3-pro-image` |
| 数列推理 | `gemini-2.5-flash-image` / `gemini-2.5-flash`（对照） |
| 回文函数 | `gemini-2.5-flash-image` |
| 600 字短文 | `gemini-2.5-flash-image` |
| 中译英 | `gemini-2.5-flash-image` |

## 结果

| 题 | 输出 | 单次成本 |
|---|---|---|
| 四行诗（雨后便利店） | 27 字，四行，平仄不讲究但意象成立 | $0.000071 |
| 200 字微小说 · flash | 428 字（要求 200 以内，超了），真有反转 | $0.000736 |
| 200 字微小说 · pro | 178 字，猫的第一人称，最后一句反杀 | $0.012090 |
| 回文函数 | 323 字，`re` + 切片，正确 | $0.000364 |
| 600 字短文 | 1176 字，结构齐全，内容偏套话 | $0.001806 |
| 中译英 | 75 字 | $0.000061 |

全部加起来 **$0.016 左右**。原文都在 `raw/`。

## 价格：没有优势

OpenRouter 上，图像版和纯文本版**同一个价**：

| 模型 | 输入 / 百万 token | 输出 / 百万 token |
|---|---|---|
| `gemini-2.5-flash-image` | $0.30 | $2.50 |
| `gemini-2.5-flash`（纯文本） | $0.30 | $2.50 |
| `gemini-3-pro-image` | $2.00 | $12.00 |

结论：拿它写字**不会更便宜**，只会多背一个内容过滤的风险。想写字，直接用文本模型。

## ⚠️ 别信单发：一次翻车实录

这一节是本次唯一有价值的教训。

**第一次跑数列题（2, 3, 5, 9, 17, ?）：**

- 图像版答 `33`，但说规律是「当前数字乘以 2 减去前一个数字」。验算：17×2−9 = 25，不是 33。**答案蒙对，规律是编的。**
- 纯文本版答 `33`，给出「每个数等于前一个数的两倍减 1」，四个例式全对；但夹了一句「减去一个递增的常数 (0, 1, 2, 3, 4, …)」，跟它自己下面列的算式打架。

据此写下结论：**图像模型的推理链被削**。

**补跑 5 次之后，这个结论作废：**

| 臂 | 5 次结果 |
|---|---|
| 图像版 | 4 次规律完全正确（差值 1, 2, 4, 8, 16）；1 次被截断，只剩「33」 |
| 纯文本版 | 5 次全部只回「33」，要求解释也不给 |

六次合计：图像版 4 次完整正确、1 次规律错、1 次被过滤；纯文本版 1 次正确但措辞自相矛盾 + 5 次干脆不解释。

**单发结果不足以支撑任何结论。** 这条在 [model-crush](../model-crush/) 里已经栽过一次，这次原样复发。

## 几个坑

1. **一轮不算数。** 同一道题连跑会变，`model-crush` 里写过，这里再验一次。
2. **内容过滤会静默截断。** `finish_reason: content_filter`，`content` 只剩答案本身，不抛错、不提示。看输出短得不正常，先查 `finish_reason`。
3. **pro 档把预算花在思考上。** `gemini-3-pro-image` 写 178 字用掉 **871 个 reasoning token**。想让它多写，得先让它少想。
4. **纯文本版反而更省话。** 明写「说明规律」，5 次全只给一个数字。指令跟随的差异可能来自模型自己的风格，样本太小，不下结论。
5. **想让模型写字，别绕道图像模型。** 同价、更慢、多一道过滤，没有任何好处。

## 为什么不进 llm-edge-cases

唯一的候选现象（推理链被削）补测之后不成立，而且就算成立也没有工程缓解可说——换个文本模型就完了。够不上那边「可复现现象 + 成因假设 + 缓解」的门槛。
