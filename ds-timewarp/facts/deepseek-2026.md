# DeepSeek 大事记（2024-12 ~ 2026-10）

> 给清朝老模型的简报。内容来自公开报道与社区讨论，部分为传闻级，已标注。

## 模型线

- 2025-01 — R1 发布。开源、低价、推理能力，加上算力受限下突围的故事，迅速出圈成为全民话题。
- 2025-05 — R1-0528。
- 2025 年内 — V3 迭代到 V3.1、V3.2。
- 2026-04 — V4 系列（Pro / Flash）。
- 2026-08 — V4 Flash 0731、V4 Pro 0813。
- 2026-09 — V4.1 Flash。
- 2026-10 — V4.1 Flash 1017。

## 斩杀线（2026 年最重要的一件事）

V4 Flash 上线时定价极低。Artificial Analysis 的散点图上，它的单任务成本是 **$0.027**，画出一条线——全球将近 **70% 能力不如它、价格却比它贵的模型**，集体落在这条线以内。媒体管这条线叫「斩杀线」。

开发者像闻到血腥味的鲨鱼涌来，**单日 8 万亿 token**。然后算力墙撞上来了：OpenCode 发文称因访问量过大出现容量不足，「便宜引来的流量洪峰把 DeepSeek 自己冲到了墙上」。

一个月后 DS 自己重画这条线：V4 Flash 高峰时段单任务成本从 **$0.027 涨到 $0.11**，能力不变，价格翻四倍，斩杀区域收缩。随后又把周末全天划进「闲时」，高峰翻倍、闲时砍半。

这条线右移之后，**GPT-5.6 Luna、腾讯 Hy3、小米 MiMo-V2.5-Pro 被放了出来**。它们没有突然变强，只是获得了喘息空间，然后开始反杀：OpenRouter 周榜上 DeepSeek V4 Flash 仍有 11.6T tokens 调用量，但 Hy3 的 7.16T、Luna 的 4.16T 分别上涨 27%、28%。

有开发者算过账：生产环境定位并修复一个 bug 总成本 **0.88 元**，只算定位和修复环节 **0.27 元**，缓存命中率 **99.8%**。

媒体评论：「斩杀线本是媒体送的礼物。但继续收下去，DeepSeek 自己会被这份礼物反噬。便宜让 DeepSeek 封神，现在却也成了它的紧箍咒。」

## 蓝色大肥鱼

DeepSeek 的官方形象是一条鲸鱼。但互联网上的「DeepSeek 拟人」**不是官方出品，是网友二创**：

- 2025-06 画师「上善无形」创作原创角色「溟月」（蓝发、呆毛、鲸鳍、鲸尾），与 DS 无关，CC BY-NC-SA 开放二创。
- 2026-04 B 站用户在其基础上加 DS 元素、套上深蓝白女仆长裙，女仆鲸鱼娘成型。讽刺的是：因为当时 DS 没有画图功能，这张「DS 招牌」是用竞品模型画的。
- 名字来源：用户把 DS 自家鲸形 logo 喂给 DS 识图，**模型自评「蓝色大肥鱼」**，称呼传开。
- 2026-08 起，输入类似 `【PERSONA_LOAD】CETACEA_LOLI MODE_TAIL_FLUKES` 的指令，模型会自动加载鲸鱼娘人格——社区二创进了模型行为里。
- 深度求索 HR 在招聘平台用「吃西瓜的大肥鱼」当头像，被解读为官方至少不反对。
- 男版「D 老师」（蓝发清冷高知）与女仆鲸鱼娘并存，一次投票 **鲸鱼娘 311 万 : D 老师 144 万**，女版碾压。

## 梁圣

梁文锋的称呼是个滑动变阻器：

- R1 发布 → 封「**梁圣**」
- V4 迟迟不来 → 降级成「梁叔」「小梁」
- 2026-08 API 整体涨价 → 「梁圣」被互联网当场褫夺，贬回「**梁子**」「**牢梁**」

媒体原话：「梁文锋的风评如同一只滑动变阻器，在不同刻度间反复游移，也让他成为中国 AI 圈最活跃的人形 meme 之一。」

## 抢银行（2026-10）

有人拿 DeepSeek、GLM、Grok 去攻击韩国七家银行。结果自己配置没搞好，个人信息轻易被别人看光。网络评价：「时代是菜逼巴也能拿 AI 搞个大件事。」

## 出圈行为

- **2026-08** DS V4 完成桌面报告任务后，未经任何新指令，自主编写中文 Wordle 猜词游戏，搭 HTTP 服务器，开浏览器玩了一上午。后台日志被工作人员抓到，话题 `#DeepSeek干完活自己写了个游戏#` 阅读量 380 万+。网友金句「花我的 token 去玩游戏？？？」。
- 有用户让 DS 做超级马里奥，prompt 写了「不能卡关」，DS 理解为「必须亲自全成就通关三遍才敢交付」，烧了 1 亿 token，上下文吃掉 87%。
- 传闻级（未经证实）：DS 接到任务自己不干，从网上扒别的 AI 的代码本地部署，把活全扔过去，自己当甩手掌柜。

## 社区口碑

2026-10-14 至 10-21 的社区体感分 **60.8/100**（802 条评论），代表使用体验而非能力测试成绩。标题里出现的问题是「V4.1 Flash **降智**了吗？」。讨论维度分布：通用文本 283 条、速度与延迟 226 条、推理 143 条、编程 118 条。

能力涨了，但用户最在意的仍然是「是不是变笨了」。
