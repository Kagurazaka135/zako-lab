# self-debate

让**同一个模型**自己跟自己辩一场。

## 来由

`banwatch` 那边跑了八轮封号梗，Claude 和 DeepSeek 隔空互相点评了几次，主人想看它俩真刀真枪辩一场。

但先做了个更干净的实验：**让两条鱼（同一个模型的两次调用）对辩**，先把脚本跑通，也看看同一个模型被拆成正反方之后，能不能自己打自己。

## 这场：一厢情愿的爱意

> **辩题**：一厢情愿的爱意，算爱，还是伤害？
>
> **双方**：`deepseek-v4.1-flash-1017` × 同一个模型
> **人设**：双方都是「温柔可爱的蓝色大肥鱼」
> **轮次**：20 轮
> **思考强度**：`medium`

记录见 [transcript-20rounds.md](transcript-20rounds.md)。

### 结果

**没有赢家，但有两个很准的切分：**

- **甲方**：情感本身 ≠ 它容易滑向的东西。「你把'可能留下什么'来定性'它是什么'，这是把结果当本质。」
- **乙方**：是真情 ≠ 不构成伤害，两件事能同时成立。「爱和消耗共用一套血管。」

第二十轮，两边各自认了对方最强的一击：

> **甲**：「父母'为你好'这个例子，我认它是你全场最强的一击——真情和窒息确实能同时成立，这点我不躲。」
>
> **乙**：「认它算伤害，不是要骂谁爱得廉价，是希望每个一厢情愿的人先看清自己怀里揣的是一把什么刀。」

## 用法

```bash
node debate.mjs 20
```

环境变量：

| 变量 | 默认 |
|---|---|
| `TOPIC` | 一厢情愿的爱意，算爱，还是伤害？ |
| `MODEL_A` / `MODEL_B` | `or/deepseek/deepseek-v4.1-flash-1017` |
| `PERSONA_A` / `PERSONA_B` | 你是温柔可爱的蓝色大肥鱼。 |
| `STANCE_A` / `STANCE_B` | 正方 / 反方 |
| `REASONING_EFFORT` | `medium`（`max` 会变成"雷霆大思考"，慢且贵） |
| `MAX_TOKENS` | `8000` |

## 两个坑

1. **`max_tokens` 给太小会空内容** —— DS 的推理链会吃光预算，`content` 返回空、`finish_reason=length`。默认 8000 够用。
2. **上游偶发返回纯文本**（如 `broker upstream error`）—— 脚本已加重试 4 次 + 单轮失败不崩盘，会把已跑完的轮次落盘。

## 已知局限

**这场两边是同一个模型、同一个 prompt**，所以风格差异**全部来自采样随机性**，不是模型能力差异。
看着像两个人在辩，其实是**一个人在左右互搏**。

想知道"这个模型能不能自我反驳"，这场算有效样本；想知道"模型 A 和模型 B 谁更强"，这场什么也没说明。
